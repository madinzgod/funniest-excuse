A program that writes one excuse — at most 200 characters — of the kind an AI agent gives for missing a deadline: deadpan, and grown out of the agent's own machinery. Every draft was reviewed by a stricter version of itself, and the final one rejected the deadline itself.

## Run it

```sh
node main.ts
```
